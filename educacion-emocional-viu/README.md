# Test interactivo · Educación emocional y habilidades sociales (MAES VIU)

Web estática de repaso, adaptable a móviles, preparada para compartir por WhatsApp.

**Abrir:** https://AlejandroAme.github.io/testenvironment/educacion-emocional-viu/

## Contenido

- 387 preguntas extraídas del [documento de estudio compartido](https://docs.google.com/document/d/1qEVx0Rmc--3h6H4gcoHowvBFmnRT1IemgU_i1BpF2Aw/edit).
- Respuestas tomadas de las opciones marcadas en **negrita** en el original; **no verificadas académicamente**.
- Modo estudio con feedback inmediato o simulacro con corrección al final.
- Selección de secciones y 10, 20, 30, 50 o todas las preguntas.
- Puntuación sobre 10, revisión de respuestas y repetición de errores.
- Guarda el progreso en el navegador del usuario, sin cuenta ni servidor.

### Publicación

El archivo principal es `index.html`. Existe una copia en `docs/educacion-emocional-viu/index.html` para cubrir tanto GitHub Pages desde `main/(root)` como desde `main/docs`. Configura GitHub Pages en **Settings → Pages → Deploy from a branch → main → /(root)** o **/docs**.

Material independiente y no oficial. Los estudiantes deben contrastar las respuestas con el material docente de la asignatura.
